Proyek Unggulan

RFID Absensi — Smart Attendance System

RFID Absensi — Smart Attendance System

RFID Absensi adalah proyek sistem presensi digital yang sedang saya kembangkan untuk membantu proses pencatatan kehadiran secara otomatis menggunakan teknologi RFID (Radio Frequency Identification). Sistem ini dirancang untuk menghubungkan kartu RFID dengan aplikasi web sehingga data kehadiran dapat dicatat dan dikelola secara terpusat.

Perpus Library — Library Management System

Sistem manajemen perpustakaan berbasis web yang dikembangkan menggunakan React.js sebagai frontend dan Laravel sebagai backend/API. Tujuan utamanya adalah membantu pengelolaan perpustakaan secara digital, mulai dari pengelolaan buku, anggota, peminjaman, pengembalian, hingga monitoring aktivitas perpustakaan.
